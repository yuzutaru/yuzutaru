# 👋 Hi, I’m Yustar Pramudana

Senior Android Engineer (Kotlin · Jetpack Compose)

I build production-ready mobile apps with a focus on performance, scalability, and clean architecture.  
10+ years shipping Android applications for banking, enterprise, healthcare, and startup teams — from legacy-modernization work to offline-first systems used by real users.

Android is my foundation. Since 2025 I've deliberately expanded into **iOS (Swift · SwiftUI)** and **web (React · TypeScript · Supabase)** — proven through a full-stack Upwork freelance project that shipped one product across React, Android, and iOS from a single OpenAPI contract.
